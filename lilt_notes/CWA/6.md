React Router
------------

So far, all our React applications have been _single-page applications_, i.e. applications which run in _one HTML page_ and communicate with the server via AJAX. The server then sends back JSON which is used to update state on the React front end.

However in many cases it can be useful to have _many pages_, even in a React application. For example a website might have a user section and an admin section, and we might want to have the admin functionality on a separate page to keep the site cleaner and more organised.

How can we do this? Some React frameworks such as _Next.js_ (which we will cover later) allow us to do this easily, but if we want to implement multiple pages in React without using a full framework we can use _React Router_. React Router allows you to setup _client-side routes_ and associate each route which a specific React component. The routes are similar in concept to Express routes but are handled purely client-side with no server required.

### How do we setup React Router?

You need to install the `react-router-dom` package, i.e.:

npm i react-router-dom

You then need to _setup the routing from your `main.jsx`_. Here is an example, taken directly from the source code of `lilt`.

import React from 'react';
import ReactDOM from 'react-dom/client';
import { createBrowserRouter, RouterProvider } from 'react-router-dom';
import App from './components/app.jsx';
import Admin from './components/admin.jsx';
import AdminAnswersMain from './components/adminanswersmain.jsx';

const router = createBrowserRouter(\[{
        path: "/",
        element: <App />
    }, {
        path: "/admin",
        element: <Admin />,
    }, {
        path: "/admin/answers",
        element: <AdminAnswersMain />,
    }
\]);

const root = ReactDOM.createRoot(
    document.getElementById('root')
);
root.render(<RouterProvider router={router} />);

Note how we use the function `createBrowserRouter()` to create a browser-based router. This takes an _array of route objects_. Each route object has a `path` (relative to the root URL of the application) and an `element` (a React component). When a user requests a particular path, the appropriate component will be rendered. So for example, assuming a server on port 3000:

*   `http://localhost:3000/` will cause `App` to be rendered;
*   `http://localhost:3000/admin` will cause `Admin` to be rendered;
*   `http://localhost:3000/admin/answers` will cause `AdminAnswersMain` to be rendered.

Note how we render a <RouterProvider> component with a `router` prop of the router we set up into our `root` element. Previously we rendered `App` directly into the `root` element.

Client Side Navigation
----------------------

Once we've setup routes, we can navigate between them. We could of course just use standard <a> tags here, but the disadvantage of this is that they _reload the entire page_. Instead, in React Router, we can use the <Link> tag to link to another route _without making a request to the server_. Here is an example:

import { Link } from 'react-router-dom';

export default function App() {
    return <>
        <h1>Main Page</h1>
        <Link to='/search'>Go to Search Page</Link>
        <Link to='/admin'>Go to Admin Page</Link>
        </>;
}

Parameters and Loaders
----------------------

We can add parameters to our routes, and then read, and act upon, these using _loaders_. Here is an example:

import { useState, useEffect } from 'react';
import SearchResults from './searchresults.jsx';
import { useLoaderData, Link } from 'react-router-dom';

export async function loader({params}) {
    const response = await fetch(\`/studentServer/${params.studentId}\`);
    const json = await response.json();
    return json;
}

export default function StudentSearch(){

    const  searchResults = useLoaderData();

    const data = searchResults.map (result => <li>{result.name}</li>);    
    return <ul>{data}</ul>

}

We have created a SearchForStudent component with an accompanying _loader_. The loader takes parameters which will come from the URL (`studentId` in this case; see below) and sends an AJAX request to a given endpoint on the server. We return the JSON from the loader and can re-use this JSON in our component with `useLoaderData()`. Note how the data from the loader is mapped to JSX in the normal way.

We then specify the loader when we setup our router, eg.

import StudentSearch, { loader as searchLoader } from './components/studentsearch.jsx';

const router = createBrowserRouter(\[{
    path: "/",
    element: <App />
}, {
    path: '/student/:studentId',
    element: <StudentSearch />,
    loader: searchLoader
}\]);

Note how we import both the component and its loader from the JSX file containing the component. We setup a route which takes a _parameter_ (`/student/:studentId`) and link it to the loader by specifying a `loader` property. As a result, when that route is requested, the loader will run, sending a fetch request to the appropriate server side route, and the component can then use it with `useLoaderData()`.

Reading Forms with React Router
-------------------------------

We can also read _forms_ with React Router. To do this we use _actions_. Here is an example component containing a form and an `action` to handle the form.

import { Form, redirect } from 'react-router-dom';

export default function AddStudent() {
    return <div> 
        <h2>Add Student</h2> 
        <Form method="post">
        <label htmlFor="name">Name:</label><br />
        <input id="name" name="name" /><br />
        <label htmlFor="course">Course:</label><br />
        <input id="course" name="course" /><br />
        <label htmlFor="mark">Mark:</label><br />
        <input id="mark" name="mark" /><br />
        <input type="submit"  value="Add Student" />
        </Form>
        </div>;

}   
    
export async function action({request, params}) {
    // The form data will be received as a FormData object
    const formData = await request.formData();
    const name = formData.get('name');
    const course = formData.get('course');
    const mark = formData.get('mark');

    // you can now send an AJAX POST request to a server route to add the student..

    redirect('/addstudent');
}

Note how we include the special React Router `Form` element to represent the form. Note that it must have a `submit` button. The accompanying _action()_ function reads the form data, it is available via `request.formData()`. This returns a `FormData` object containing the form data, which we read with `get()` plus the name of each form field. Note how it is the _name_ of the form fields which is read, NOT the id. Once we've done this, we can then use the data to send an AJAX request to a server-side route to add the data to the database.

We can then add the action when we setup the router, e.g:

import AddStudent, { action as addStudentAction } from './components/addstudent.jsx';

const router = createBrowserRouter(\[{
    path: "/",
    element: <App />
}, {
    path: '/addstudent',
    element: <AddStudent />,
    action: addStudentAction
}\]);
